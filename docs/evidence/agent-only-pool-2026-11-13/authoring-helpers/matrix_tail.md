## Guard notes

* **GN-1 (GET, idle path; guard group G-03).** For a dequeued idle conn with idle age `a` and IdleTimeout `T`: `T > 0 ∧ a > T` → discard (Close: o−1, Close callback) and retry the loop; else Ping configured ∧ Ping error → discard and retry; else return it. Boundary: `a = T` is **not** expired (`Before` is strict, channel.go:116); `T ≤ 0` disables the age check. The state after the Get depends on what is left: i−1 ≥ 1 → Open_Idle; i−1 = 0 → Open_Empty_BelowCap (o < X) or Open_Empty_AtCap (o ≥ X). Outcome: proven (G-03).
* **GN-2 (GET dispatch; G-02).** `conns == nil` → reject (checked before the loop, channel.go:105). Idle available → idle path. No idle conn: `o ≥ X` → wait; else `factory == nil` → reject; else create. The at-cap test precedes the released test (channel.go:133 before channel.go:150): a Get that saw the pool open, then reaches the lock after Release, waits forever when o ≥ X (boundary probe in guard-results.txt; → Q-05). Outcome: proven (disjoint, covering).
* **GN-4 (PUT; G-04).** nil → reject (before the lock); released → Close (no-op after Release); w ≥ 1 → hand-off to the oldest waiter; i < M → enqueue; i = M → Close (o−1). With M = 0 every Put without a waiter closes. Outcome: proven.
* **GN-5 (CLOSE; G-05).** nil → reject; Close callback cleared (released) → return nil, nothing else; else o−1 and Close callback. The decrement is unconditional on connection identity. Outcome: proven.
* **GN-6 (Factory result; G-06).** err ≠ nil → return (nil, err), o unchanged, the conn value ignored; err = nil → o+1, return conn (nil conn included). Target state after FACTORY_OK: o+1 ≥ X → Open_Empty_AtCap (the cell's target); o+1 < X → Open_Empty_BelowCap; stranded waiters → Open_Waiting_BelowCap (or Open_Waiting when o+1 ≥ X); an idle conn left by a racing Put → Open_Idle. Outcome: proven.
* **GN-7 (waiting Get woken; G-07).** channel closed (`!ok`) → `ErrMaxActiveConnReached`; else expired hand-off → discard and retry; else return. No code closes a waiter channel, so the first branch is unreachable (→ Q-01). Outcome: proven (the dead branch is a reachability finding, not a guard violation).
* **GN-8 (RELEASE; G-08).** conns == nil → return; else clear, close channel, drain and close idle conns. Outcome: proven.
