## Supplemental seam review

- Example network Factory uses net.Dial with no supplied deadline. Go 1.27.3 src/net/dial.go:425 ("Dial connects to the address on the named network.") documents the connection role (Jev DialRole supported). The RPC fixture uses rpc.DialHTTP. src/net/rpc/client.go:239 ("DialHTTP connects to an HTTP RPC server") documents its role (Jev supported), and src/net/rpc/client.go:249–269 implements network dial, CONNECT response checking and closes on failed handshake. This seam can fail or block, and the pool makes no timeout guarantee. Q-09, Q-21.
- Example close delegates to net.Conn.Close. src/net/net.go:136 ("Any blocked Read or Write operations will be unblocked and return errors.") supplies the NetClose guarantee (Jev supported), and the next line allows waiting for pending data. RPC Close delegates to underlying codec and returns ErrShutdown on an already closing connection, src/net/rpc/client.go:281–282 (both Jev checks supported). The guarantees are specific to those adapters. Q-10.
- Go Time.Before compares strict chronological precedence, src/time/time.go:280 ("Before reports whether the time instant t is before u.") (Jev supported). The observed call site checks age only upon receipt. Q-17.
- Logrus Debugf is a Debug-level emission, dependency exported.go:187 ("Debugf logs a message at level Debug on the standard logger.") (Jev supported). Enabled hooks run synchronously, dependency entry.go:280 ("tmpHooks.Fire(entry.Level, entry)"). Returned hook error goes to stderr. A configured hook that reenters a mutex-taking pool method can block admission, and its panic behavior is uncontracted by this pool. Q-08, Q-21.
- Go RWMutex establishes an unlock-to-later-lock synchronization relation, src/sync/rwmutex.go:32–38. This covers the channel pointer and counter branches that acquire it. It does not protect reads that bypass it, which matters for Ping vs Release. Q-06.
