## Guard notes

- G-01 admission: Open rejects; HalfOpen rejects at Requests >= MaxRequests; Closed or below-budget HalfOpen admits. See guard-results.txt.
- G-02 completion freshness: generation equal or unequal after refresh. See guard-results.txt.
- G-03 half-open success after increment: below threshold stays, equality or above closes. See guard-results.txt.
- G-04 default closed trip: five or fewer stays, six or more trips. See guard-results.txt.
- G-05 interval and timeout default for negative or zero; positive overrides. See guard-results.txt.
- G-06 MaxRequests default at zero, explicit positive. See guard-results.txt.
- G-07 clock: unarmed Closed and HalfOpen do not expire; for armed modes now below or equal to deadline stays, above refreshes. See guard-results.txt.
- G-08 custom trip callback return true or false; failure and blocking tracked separately. See guard-results.txt.
- G-09 completion outcome: success or failure after generation acceptance. See guard-results.txt.
- G-10 optional callbacks: installation and default selection by presence and distinct-state notification. See guard-results.txt.
- G-11 default classifier and panic recovery: nil or nonnil classifier input; nil recover cannot submit a failed report. See guard-results.txt.
