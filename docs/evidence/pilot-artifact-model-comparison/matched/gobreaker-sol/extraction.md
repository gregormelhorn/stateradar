## Follow-up on escaped continuation

A caller can overwrite an exported wrapper value after obtaining its continuation. A serialized assignment changes the backing core subsequently looked up by the continuation, while its captured generation remains from the original core. If the replacement happens to have the same generation, the report can apply there.
