## Guard notes

- G-01 New bounds: 0 ≤ InitialCap ≤ MaxIdle ≤ MaxCap. Equality accepted at all three comparisons. G-02 New config and callback presence. Nil Config panics before validation. Factory and Close nonnil, optional Ping. G-03 Get at capacity uses >=, including zero and counts above cap. Below cap factory presence matters after snapshot; a negative count can arise via Close on duplicate/foreign values. G-04 age: timeout > 0, strict expiry after equality on buffered and handoff paths. G-05 Put: prefer waiter if queue > 0, otherwise channel readiness, default overflow. A zero idle buffer cannot retain idle values. Without a simultaneous receive or queued handoff, Put takes overflow. G-06 channel readiness and captured snapshot, G-07 callback results and side effects, G-08 request reception and shutdown sequencing, G-09 constructor loop, G-10 nil payload, availability and captured-close gates. G-01–G-05 and G-09–G-13 proven for their sampled guard variables. G-06–G-08 and G-14 not-formalizable for runtime scheduling, callback effects and clock samples. Exact boundary assignments in guard-results.txt.
