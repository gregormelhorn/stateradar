# Matched comparison of routed and hybrid pilots

The four live sessions used pack `0a88714` with the same component SHAs, Codex model, reasoning effort, ChatGPT login, selective tool output and Jev version. The routing variant was the experimental difference. Pool ran routed first and gobreaker ran hybrid first. See the [protocol](protocol.md), [finding comparison](coverage.md) and [independent controls](control-results.txt).

Both Pool variants independently recovered and tested the historical P-04a, the below-capacity branch, Release stranding Gets and competing same-caller acquisitions. Both gobreaker variants recovered all four independent control findings. Hybrid tested more branches in some cases, including Pool caller abandonment and gobreaker notification during stale-report expiry. Routed already covered the core schedules.

The Codex service stopped Pool routed at the final reporting stage with a cybersecurity filter message. The completed-turn event and local counters for that session are absent. All five saved-artifact checks passed in the postflight. Pool hybrid completed with a full token report and spent $0.004539 on the Flash schedule call. Flash supplied an intermediate state for P-04a and Codex resolved the ordering and verified it with a probe. Codex corrected six of eight Pool schedule proposals. Both hybrid matrices matched fresh rendering and both sidecars regenerated byte for byte after deletion in fresh copies. Pool hybrid's first blind table passed row-presence checking despite duplicate rows. The pilot commissioned a fresh blind response and verified unique rows. The accepted blind answer still flagged `Close` and `CloseResult` as as-is-dependent.

At gobreaker, hybrid used 47.2% more total Codex tokens, 29.2% more input excluding cache hits and 35.3% more output than routed. It used 14 retained-log reads versus 7. Its run added 362 seconds and $0.007528 to the settled Flash/Jev ledger. The hybrid schedule call cost $0.005019 of that ledger. Codex retained three of eight Flash proposals and corrected five even though all eight passed mechanical citation checks.

The routing ledger uses observed provider token counts and peak cache-miss Flash rates. DeepSeek publishes lower weekend and cache-hit rates. The pack does not record Flash cache-hit tokens, so ledger values are comparable estimates. Jev uses its published input rate. Codex via ChatGPT login has token counters but no per-run dollar amount in these records. [DeepSeek pricing](https://api-docs.deepseek.com/quick_start/pricing/) and [Jev pricing](https://help.typesafe.ai/articles/5187202169-how-much-does-jev-cost).

Keep routed as the current standard and hybrid as opt-in. For further evaluation, measure the deterministic renderer and the Flash schedule call independently. These runs compare the combined workflow and do not identify the contribution of each change. The single pair per component does not estimate variance.

## Follow-up work caused by the workflow

The gobreaker retained-log requests can be traced to their original commands. Of the seven additional requests in hybrid, four came from race-test log inspection. Two of those were invalid line-range requests against a 52-line log. The other three additional requests read source, the ordinary extraction draft, and the Flash schedule proposal respectively. These counts include failed requests. Most additional retained-log requests therefore came from test-log handling. The logs do not establish that Flash caused the total Codex cost increase.

The semantic correction burden is separate. Codex corrected six of eight Pool schedule proposals and five of eight gobreaker proposals. These counts measure review outcomes, and do not measure the time or credits spent on each correction. Both variants use Flash for extraction and blind Part B, so this experiment tests the added schedule sweep and renderer together. A source citation passing mechanical validation does not establish a possible interleaving.

Evaluate total cost per independently verified result, including drafting, review, retries and any stronger-model escalation. Compare routed, routed with the renderer, and routed with both renderer and schedule proposals before attributing an effect to Flash. Then compare steering models on the selected workflow. Keep P-04a and the other external controls outside the drafting inputs. Record missing findings, invalid accepted schedules, successful completion and operator recovery alongside cost. Additional gate counts alone do not establish higher semantic quality.
