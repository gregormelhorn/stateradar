# Three-way routing comparison

All six attempts used pack `1a55d94`, pinned component revisions, GPT-6.1 Sol medium through ChatGPT login, selective output and Jev 1.14.0. Pool order was routed, matrix, hybrid; gobreaker order was hybrid, matrix, routed. The two component sequences ran concurrently with separate sandboxes. CLI was 0.167.0-alpha.4.1 and Go was 1.27.3. See the [preregistered protocol](protocol.md).

Five attempts completed. Pool routed was stopped by the Codex service's cybersecurity filter after 15:42. Its final Codex usage is unavailable. It must not be priced at its $0.017112 provider ledger or counted as a completed successful pilot. Independent postflight of the saved artifacts passed matrix, guards and blind coverage. The sidecar was not yet generated, so sidecar and reachability failed. No model retry was made to work around the service refusal.

For Codex, uncached input is total input minus cache hits. Standard credits are `uncached * 50/M + cached * 2.5/M + output * 250/M`. Reasoning is already part of output; cache-write counts were zero in all completed runs. The [published Codex credit rates](https://learn.chatgpt.com/docs/pricing#token-rates) support that normalization. Actual subscription allocation or a differently priced credit purchase can change dollar cost.

Flash/Jev ledgers retain all settled calls and have zero outstanding reservations. They use peak Flash cache-miss rates; [DeepSeek's weekend and cache-hit rates](https://api-docs.deepseek.com/quick_start/pricing/) can make actual charges lower. Cache counters were not retained, so exact billed Flash cost is unavailable. [Jev pricing](https://help.typesafe.ai/articles/5187202169-how-much-does-jev-cost) applies to input. Codex represents more than 97% of the combined equivalent in every completed run. This comparison does not meter this supervising audit chat, runner development, or human review, and therefore is not a fully allocated project-cost invoice.

## Finding quality and completion

All three Pool attempts reproduced the historical P-04a at capacity, including a later Get bypassing the first waiter and a subsequent Put waking it. All distinguished the below-capacity redundant Factory branch. Every gobreaker variant found and tested all four independent controls. Shared core findings also cover second acquisitions, shutdown/waiter behavior, stale results, repeated callbacks and reentry. [Behavior crosswalk and differences](coverage.md), [executed pilot tests](behavior-results.txt), [independent controls](control-results.txt).

Additional depth varies. Pool matrix directly tested the cleared-Ping panic and a drain interrupted by panic. Pool hybrid and routed obtained race-detector evidence for Ping/Release. Gobreaker routed and hybrid reproduced the upstream test race; matrix did not run that full race suite. Matrix's extra states/cells and question counts are not extra independent findings. All domain questions remain open. The number of gates also differs by workflow, so 7/7 does not by itself demonstrate better semantic quality than 5/5.

All four structured matrices and sidecars regenerated byte for byte after deleting the generated files in fresh copies. [Regeneration output](fresh-regeneration.json). Blind outputs were reviewed for code-derived catalogue information, inline as-is qualifiers and vocabulary drift. Row-presence gates do not prove independence or unique rows.

The old EOF-overrun errors, dict-as-list AttributeErrors and accidental compilation of probe directories did not recur. Source probes consistently live under `_probe` and are injected with overlays. One new empty-stdout read failed in gobreaker routed. Top-level routing help was also rejected in Pool routed and gobreaker matrix. Both newly observed runner cases were fixed after the comparison with observed red/green tests; the measured SHA deliberately remains unchanged. The post-comparison code was not rerun through six paid pilots.

The extra schedule sweeps produced 15 candidates: 2 kept, 12 corrected and 1 unsupported. Citation validity had not established possible lock ordering. The schedule calls themselves cost $0.005013 for Pool and $0.004127 for gobreaker in the conservative ledger. Their review and incorporation are included in Codex's total; there is no defensible per-correction dollar allocation in the logs.

Pool matrix commissioned three blind responses: one superseded after catalogue repairs, one with repeated keys, then the accepted table. Pool hybrid needed four: an initial catalogue, a prefixed response missing rows, one with duplicate keys, and the accepted table. All remain in the ledger. Gobreaker hybrid retained and classified 118 situation rows over 62 IDs rather than requesting a replacement for multiple rows. This difference in review strategy contributes to cost variance. A shared explicit policy for valid situation rows versus duplicate keys would make future comparisons cleaner.

Other repairs were citation corrections before Jev dispatch, catalogue syntax and annotations, premature artifact checks, wrong dependency paths and one Python quoting error. Gobreaker routed's malformed Flash test draft was paid, rejected and replaced by direct source review. Raw log references and request origins are in [measurements](measurements.json) and the [command audit](command-audit.txt). An outer postflight initially used an unresolved /tmp path and hit the macOS sandbox path rule; rerunning the same deterministic checks with /private/tmp corrected that audit invocation. This did not modify the pilot artifacts or add provider calls.

## Recommendation

Keep routed as the provisional general workflow. It was cheapest on gobreaker with full control coverage and strong extra probes. Keep the matrix generator available for reproducible rendering, but do not justify a default switch by cost savings: this comparison did not show them. Use the added Flash schedule sweep selectively when an independently reviewed gap warrants it, rather than on every component. Neither the small Pool price difference nor the single service cutoff supports a general claim about causal reliability.

The next cost reduction should target predictable repair work shared by all variants: canonical event/coverage fields, exact citation extraction and a clear blind-row multiplicity contract. Then test a lower-cost Codex controller with the workflow and behavioral acceptance held fixed. The current evidence does not justify weakening the source review, blind independence checks or behavioral probes.
