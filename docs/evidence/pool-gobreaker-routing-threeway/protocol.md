# Three-way routing protocol

Compare `routed`, `matrix` and `hybrid` at the single pack commit that contains this protocol. Each run records the full SHA in experiment.json. Source revisions are Pool 6084537e520652192f41aebfd88d822c00b9447a and gobreaker 27b8e2cfc65aacd09abb3968455e4b01df4a83fa. All sessions use GPT-6.1 Sol medium through ChatGPT login, selective output, Jev 1.14.0, a fresh blind Flash Part B, no companion claims, an independent default $2 provider ledger and a 2700 second timeout. Record installed CLI and Go versions. Only the routing variant changes within a component.

Pool order is routed, matrix, hybrid. Gobreaker order is hybrid, matrix, routed. Run one component of each kind per wave in separate sandboxes. Never overlap two Pool runs because the upstream RPC tests bind a fixed port. Control tests and reference analyses stay outside the pilot sandboxes. Keep every failed attempt and repair in the measurements. Do not selectively replace a poor run.

All variants require the five existing gates. Matrix and hybrid additionally require render identity and strict sidecar regeneration. Check blind-package independence separately from row coverage. Review findings by concrete behavior and evidence, not by question count or local IDs. Use the Pool P-04a probe and the four gobreaker controls from the preceding matched comparison as independent behavioral controls. Retain the same detailed coverage checklist in that comparison's protocol. Additional findings must have citations or behavioral evidence and unresolved intent must remain a question.

Primary outcomes are total model cost and finding quality. Include all Codex controller usage, internal repairs, failed paid Flash/Jev calls and successful calls. Report completion and missing usage explicitly. Compute Codex standard credit equivalents as uncached input * 50/M + cached input * 2.5/M + output * 250/M. Reasoning is already part of output. At an assumed USD 0.04 per credit, report a dollar equivalent separately from actual account charges. Provider ledgers conservatively use peak cache-miss rates; actual off-peak/cache charges may be lower. Never call the ledger the combined cost. This audit's own unmetered supervising chat and human review are not included, so record that limit explicitly.

Count failed tool commands and classify repairs by cause, including read ranges, schema assumptions, Go probe compilation, artifact/checker repairs, expected behavior-probe failures and provider failures. A nonzero command by itself is not an avoidable error. Record retained-log reads and explain their purpose. One run per arm cannot estimate a failure probability or establish causation from an extra read alone.
