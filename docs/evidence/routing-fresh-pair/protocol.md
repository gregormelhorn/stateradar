# Matched bounded full-pilot comparison

Prepared before model analysis. No human review. Primary component: one
`Cache` in hashicorp/golang-lru at `2bb29091a6c341aba625d23fea354c4fbaef5d6f`,
including its simplelru and linked-list callees and API contract comments.
The public repository may have appeared in model pretraining, so novelty is
only relative to prior StateRadar experiments. Candidate reserve for later,
not read or evaluated: sony/sonyflake at `f167a9d53145b661d05ac28b5702b6f29ea9c502`;
its suitability is not yet assessed. Do not use it to tune this comparison.

A separate source-grounded reference set is prepared, executed and reviewed by
an isolated AI session before the two pilots. It is not provided to either
pilot. The comparison is one full 02-pilot per arm at the same pack/source
revision, Sol medium, isolated checkouts, identical finding-neutral scope and
mandatory gates. In agent-only the model provider credentials are absent and a
separate fresh Codex session receives only a verified Part-B blind package. In
routed, Flash drafts, Jev checks and `blind` receives its prescribed restricted
package. Source code, matrices, analyses and reference answers must never
enter the blind session; preserve and classify any package contamination.

One paired run is a feasibility comparison, not evidence of a population
benefit. Compare completeness, all gates, reference cases, false findings,
open-question preservation, wall time, Codex credits and provider ledger.
A weak/incomplete run is a result, not equivalent success. Do not decide domain
semantics. Do not change prompts or source between arms. The primary references
must be frozen and hidden from the agents. Any repeated runs or expansion to the
reserve component require a separately declared future experiment.

Budget: $5 combined soft model-cost equivalent for the initial pair and the
reference review, including measured Codex and local provider costs; each pilot
uses its own $2 provider ledger. Stop when reported known subtotal reaches the
limit or usage is incomplete/unsettled; in-flight calls can overshoot a soft
limit, and supervising-session cost is not observable to this controller.
Time limit 1200 seconds per arm. Retain failed attempts, partial outputs,
unknown usage and all blind-session accounting. Missing accounting is not zero.
