# Scope and extraction

One Cache receiver and its simplelru store and internal ring. Actors: constructor/publication owner, owner issuing Purge/Resize, possibly parallel API callers and registered callback. Exclude ARC, TwoQueue, expirable cache, publication/application wiring, GC and callback internals. No neighbouring model supplied. Synchronous cache calls change persistent recency, membership and capacity, with a per-invocation callback lifecycle. There is no background worker, Close, cancellation signal, deadline or restart API. Restart means publishing another receiver; an old reference still names the old receiver. Q-09 covers intent.

## States, events and effects
- Uninitialized: zero Cache or outer pointer from a failed constructor has nil store (lru.go:35 ("c = &Cache[K, V]{"), lru.go:42 ("c.lru, err = simplelru.NewLRU(size, onEvicted)"), simplelru/lru.go:26 ("return nil, errors.New("must provide a positive size")")); callback registration can exist on failed construction (lru.go:36 ("onEvictedCB: onEvicted,"), lru.go:38 ("if onEvicted != nil {")). A nil receiver is a separate fault.
- Initialized: positive Empty, BelowCapacity, AtCapacity; zero Disabled; negative NegativeCapacity. Negative can retain entries when signed subtraction wraps (simplelru/lru.go:157 ("diff := c.Len() - size"), simplelru/lru.go:158 ("if diff < 0 {"), simplelru/lru.go:164 ("c.size = size")). Callback nil/registered is immutable at runtime (lru.go:36 ("onEvictedCB: onEvicted,"), lru.go:41 ("}")) and orthogonal. Multiple callback invocations can coexist in any initialized state.
- Add existing overwrites and refreshes (simplelru/lru.go:52 ("if ent, ok := c.items[key]; ok {"), simplelru/lru.go:53 ("c.evictList.MoveToFront(ent)"), simplelru/lru.go:54 ("ent.Value = value")); new inserts at newest, then can evict one (simplelru/lru.go:59 ("ent := c.evictList.PushFront(key, value)"), simplelru/lru.go:60 ("c.items[key] = ent"), simplelru/lru.go:62 ("evict := c.evictList.Length() > c.size"), simplelru/lru.go:65 ("c.removeOldest()")). ContainsOrAdd and PeekOrAdd observe and conditionally insert under one writer lock (lru.go:126 ("c.lock.Lock()"), lru.go:127 ("if c.lru.Contains(key) {"), lru.go:131 ("evicted = c.lru.Add(key, value)"), lru.go:149 ("c.lock.Lock()"), lru.go:150 ("previous, ok = c.lru.Peek(key)"), lru.go:155 ("evicted = c.lru.Add(key, value)")).
- Get hit touches recency; miss returns zero/false (simplelru/lru.go:72 ("if ent, ok := c.items[key]; ok {"), simplelru/lru.go:73 ("c.evictList.MoveToFront(ent)"), simplelru/lru.go:76 ("return")); Contains and Peek do not touch (simplelru/lru.go:82 ("_, ok = c.items[key]"), simplelru/lru.go:90 ("if ent, ok = c.items[key]; ok {")). Remove hit removes; miss false (simplelru/lru.go:99 ("if ent, ok := c.items[key]; ok {"), simplelru/lru.go:101 ("return true"), simplelru/lru.go:103 ("return false")). Keys/Values independently allocate and walk oldest to newest (simplelru/lru.go:125 ("keys := make([]K, c.evictList.Length())"), simplelru/lru.go:127 ("for ent := c.evictList.Back(); ent != nil; ent = ent.PrevEntry() {"), simplelru/lru.go:136 ("values := make([]V, c.evictList.Length())"), simplelru/lru.go:138 ("for ent := c.evictList.Back(); ent != nil; ent = ent.PrevEntry() {")). - Removal decrements ring count and deletes map, then captures notification (simplelru/lru.go:177 ("c.evictList.Remove(e)"), internal/list.go:102 ("l.len--"), simplelru/lru.go:178 ("delete(c.items, e.Key)"), simplelru/lru.go:180 ("c.onEvict(e.Key, e.Value)")). NaN can be inserted and iterated without being equal to itself: map delete fails to match. Cached orphan keys remain after eviction or purge (Q-04); counter is ring length only.
- Invocation track: captured under lock, delivered after unlock, then normal return, abort or wait. Single delivery copies payload and truncates slice (lru.go:84 ("k, v = c.evictedKeys[0], c.evictedVals[0]"), lru.go:85 ("c.evictedKeys, c.evictedVals = c.evictedKeys[:0], c.evictedVals[:0]")); batch detaches then replaces buffers (lru.go:65 ("ks, vs = c.evictedKeys, c.evictedVals"), lru.go:66 ("c.initEvictBuffers()"), lru.go:190 ("if c.onEvictedCB != nil && evicted > 0 {"), lru.go:192 ("c.initEvictBuffers()")). Public callback runs in the caller post-unlock (lru.go:68 ("c.lock.Unlock()"), lru.go:72 ("c.onEvictedCB(ks[i], vs[i])"), lru.go:194 ("c.lock.Unlock()"), lru.go:197 ("c.onEvictedCB(ks[i], vs[i])")). No rollback, cancellation, retry or replay. Callback panic/Goexit can skip tail. Waiting/aborted callers do not unregister a pending callback or revert storage. Get returns value directly (simplelru/lru.go:74 ("return ent.Value, true")); no lease, waiter queue, capacity consumed per read, or release API.
- Lock overlay: shared reader, writer, free, stranded reader/writer after recovered panic. Nil store or unhashable dynamic interface key can panic after acquisition and skip normal unlock (lru.go:96 ("c.lock.Lock()"), lru.go:97 ("value, ok = c.lru.Get(key)"), lru.go:98 ("c.lock.Unlock()"), lru.go:105 ("c.lock.RLock()"), lru.go:106 ("containKey := c.lru.Contains(key)"), lru.go:107 ("c.lock.RUnlock()")). Reader panic can leave subsequent reads possible until writer pending; writer panic blocks all lock takers. Cap takes no lock. User callback panic follows unlock, a different fault.

## Callee guarantees
- NewLRU nonpositive → nil/error (simplelru/lru.go:25 ("if size <= 0 {"), simplelru/lru.go:26 ("return nil, errors.New("must provide a positive size")")); positive → initialized ring/map (simplelru/lru.go:31 ("evictList: internal.NewList[K, V](),"), simplelru/lru.go:32 ("items:     make(map[K]*internal.Entry[K, V]),"), simplelru/lru.go:35 ("return c, nil")). Its documentation simplelru/lru.go:23 does not promise range, allocation or invalid receiver behavior. The outer pointer is allocated before delegation.
- simplelru/lru_interface.go:9-21 promises normal recency and projection behavior, no timeout, dynamic-key recovery or error channel; normal map operations still obey the Go equality/hash contract. Inferred from Go language map and comparison rules; public probes independently observe NaN and bad dynamic key outcomes. Same gap for removal (interface lines simplelru/lru_interface.go:23-27).
- simplelru/lru_interface.go:29-45 promises per-call projection and clearing, no joint snapshot, value cloning, timeout or teardown fence. Resize promises count at simplelru/lru_interface.go:47. Implementation computes signed diff, clamps, loops until diff calls even if empty, then writes size (simplelru/lru.go:157 ("diff := c.Len() - size"), simplelru/lru.go:158 ("if diff < 0 {"), simplelru/lru.go:161 ("for i := 0; i < diff; i++ {"), simplelru/lru.go:170 ("if ent := c.evictList.Back(); ent != nil {"), simplelru/lru.go:164 ("c.size = size")); no documented invalid-size result.

The literal root sentinel is an identity reference, not a computed boundary (internal/list.go:45 ("root Entry[K, V] // sentinel list element, only &root, root.prev, and root.next are used")).
- RWMutex contract (installed Go sync/rwmutex.go:16-36 and sync/rwmutex.go:141-143): multiple readers or one writer, waiting writer excludes new readers, unlock synchronizes before subsequent acquisition, and no copy after first use. No deadline. Call-site confirms locked observers except Cap; no claim about external callback data ordering. Q-11 includes malformed receiver and copied-lock NAT violations.
- Callback contract (lru.go:31-32, simplelru/lru.go:12) promises optional notification but no return bound, delivery order, reentrancy, retry or failure policy. Callback has no error result (lru.go:33 ("func NewWithEvict[K comparable, V any](size int, onEvicted func(key K, value V)) (c *Cache[K, V], err error) {")); Goexit specifically terminates its goroutine and runs defers (installed Go runtime/panic.go:672-674). Panic and Goexit at the callback boundary are separately observed. Do not infer a user guarantee from adapter behavior. Q-05/Q-06/Q-08/Q-11.
