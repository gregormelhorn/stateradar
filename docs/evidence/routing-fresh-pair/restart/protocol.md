# Restart protocol

The blocked attempt and its unknown residual costs remain in `../attempt` and
are not counted as zero. Start a separate $5 soft budget for the new blind
smoke plus both fresh full pilots. Previously incurred reference preparation,
smoke and the partial first pilot are reported separately. Unreported prior
costs and supervising-session cost remain unknown; this cap does not bound the
combined expenditure of both attempts. In-flight calls can overshoot the cap.

Reuse the frozen, independently AI-reviewed reference, which neither new
pilot may inspect. The preliminary direct pilot saw the component, but the new
pilots and their blind sessions are fresh independent model sessions. Use the
same source and pack revisions, one direct arm and one routed arm, one $2
provider ledger per arm, and all the pilot and blind gates from the original
protocol. Neither the aborted arm nor the fictional smoke is a result in the
comparison. Preserve both and do no human review. A single pair cannot establish
population-level effects.

Before the pair, run a small actual fresh blind session through the same MCP
server and runtime CLI. Its complete metered cost is included in this restart's
budget. The smoke uses only a fictional lamp and contains no real component
source. Verify its blind coverage and independently rederive its controller and
blind costs before launch. If any model usage is unknown or unsettled, stop.
