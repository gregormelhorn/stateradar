# Source-fragment routing label evaluation

Declared before Jev and comparator calls. No human review. Twenty prewritten
checks on four distinct pinned public Go components; Once/Pipe development,
Buffer/Value held out from development. The public sources and behavior were
used in earlier GEPA experiments, so these are previously exposed components,
not a fresh or contamination-free benchmark. A supervising AI authored all
checks and proposed labels before seeing any reference, Jev or comparator
output. A separate isolated Codex session receives source plus checks without
proposed labels or model results; it independently proposes the reference
verdicts. Attribution does not prove independence or correctness. The operator
must read and record each reference reason. Disagreements stay OPEN and are
reported; they cannot silently become a domain decision or disappear.

The task evaluates evidence in the exact cited single-line fragment. Context
may interpret the subject, but must not add an unquoted event ordering or
callee error contract. A label about a source comment describes what it says,
not necessarily actual runtime behavior. The Value Load comment and the
implementation after Swap may conflict; keep the scope question OPEN. Each
label is `supported`, `contradicted`, or `unclear` as evidence support, never a
domain decision. Freeze source, checks, proposed labels and independent reviews
before any Jev/comparator call. If independent and authored labels differ,
record the question and exclude only those specific checks from accuracy
counts; retain their raw observations and explicitly count exclusions.

Run Jev 1.14.0 `jev-batch` and an independent fresh, isolated source-only Codex
judge on the identical checks, two development components first. Record all
raw verdicts, cited identities, token/cost and errors; no tuning or threshold
changes after seeing development. Then unlock and run the predeclared held-out
components. The comparator receives no labels or reference review. The baseline
is direct Codex judgment on supplied claims: it is not a full agent-only pilot
and does not measure Flash drafting, end-to-end statechart coverage, or the
supervising agent's own work. Jev receives identical source and checks. Compare
confusion matrices, false support, missed support, unclear results and costs;
ordering-scope probabilities are inspected individually, not thresholded.
Repeat calls are not prescribed here, so the sample cannot establish variance.
Use no automatic acceptance, escalation or new prompt promotion.

One ledger with a $2 cap covers Jev tool calls; Codex reference and comparator
costs are tracked separately as credit-equivalent estimates. Allow at most eight
isolated Codex attempts per group and $3 soft equivalent per group; one in-flight
call can exceed the soft cap. Retain failed and structural repair attempts,
unsettled costs, and original outputs. If provider output fails, record BLOCKED
rather than replacing it with a plausible result. Runtime tests are not a
substitute for the fragment-scoped question, which is what Jev is asked.
