## Guard notes

G-01 Done closed at locked check vs open; G-02 fast / oversized / queue at free == n, n == size, queue length 0/1. G-03 TryAcquire at free == n and queue length 0/1. G-04 signed subtraction at resulting cur == 0. G-05 nil head vs blocked vs fitting at free == head weight. G-06 cancellation ready already closed vs entry still linked. G-07 cancellation rescan only for front and free > 0. G-08 Done recheck after ready. G-09 initial select is dynamic-state / not-formalizable. G-01–G-08 proved under NAT-01; G-04 includes a deliberate over-release boundary. Outcomes and ±1 probes are in guard-results.txt.
