# Extraction and scope

Scope: one Weighted instance, constructor, Acquire, TryAcquire, Release, and the Context.Done/Err and private ready-channel boundary. Actors are request callers, holders, and cancellation owners. Callers can overlap roles. External work, worker shutdown and independent instances are outside the single-instance boundary. Model links: no neighboring model supplied. Go Context owns deadlines, parent propagation and Done closure; Go Mutex owns exclusion/synchronization. The caller owns released weight discipline.

## Callee guarantees and failures

Language operations also used: channel construction creates a fresh unbuffered channel; receiving a nil channel blocks forever; a channel close synchronizes before a receive observing that closure; a closed channel cannot be closed again. Go language specification at https://go.dev/ref/spec#Close and memory model at https://go.dev/ref/mem. Here close is private and one-shot after unlink under lock. The scheduler gives no immediate-resume promise. No external storage, worker callback or retry seam is invoked.
